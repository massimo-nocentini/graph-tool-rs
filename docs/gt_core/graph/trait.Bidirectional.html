Expand description

In-edges. Directed views only.

in_edges(v, undirected_adaptor) returns make_pair(iter_t(), iter_t()) – a default-constructed empty range (graph_adaptor.hh:219-227) – so any generic algorithm walking in-edges on an undirected view produces a wrong answer rather than an error. There is no implementation of this trait for Und, so the same call is error[E0599].
