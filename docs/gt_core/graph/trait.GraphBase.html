Expand description

Counts, bounds and identity.

Required Methods§

Source

fn graph_id(self) -> GraphId

Identity of the underlying storage. Views forward it unchanged, so a property map sized for g is accepted by Und(g).

Source

fn num_vertices(self) -> usize

The honest number of vertices this view exposes.

A filtered view returns the filtered count, and self.vertices().count() == self.num_vertices() holds. filt_graph returns the unfiltered count (graph_filtered.hh:316) and the header admits at :301-312 that the identity is thereby lost.

Source

fn num_edges(self) -> usize

The honest number of edges this view exposes, counted from EdgeList::edges semantics – each edge once, never by summing degrees.

Source

fn vertex_bound(self) -> VertexBound

Allocation bound of the vertex index space, always of the unfiltered storage. This, never num_vertices, is what sizes a property map.

Source

fn edge_bound(self) -> EdgeBound

Allocation bound of the edge index space, always of the unfiltered storage.
