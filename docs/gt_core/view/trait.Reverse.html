Expand description

Reversing a directed view. An involution: g.reverse().reverse() is g, as a type, not merely as a value.

There is no implementation for Und, so reversing an undirected view is error[E0599] rather than the silent no-op that graph_filtering.hh:77’s reversed && is_directed_v<directed_t> guard produces.
