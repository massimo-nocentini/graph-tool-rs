Trait PropValue

pub trait PropValue: Sealed + 'static {
    type Elem: PropValue;

    const KIND: ValueKind;

Expand description

A member of the value universe.

Elem replaces the whole last_type_func_t family (dispatch.hh:113, :301-385) by projection rather than by search: velem_dprop_t and its siblings collapse a dispatch axis to one element, but hana::for_each still runs over that element, still performs the three-way any_cast probe, and can still reach the DispatchNotFound throw. An associated type adds no arm, no probe and no failure mode.
