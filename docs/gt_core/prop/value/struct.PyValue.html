Struct PyValue 

Source 
pub struct PyValue { /* private fields */ }
Expand description

The Python member of the universe.

!Send and !Sync by construction. pyo3’s Py<T> is unconditionally Send + Sync (pyo3-0.22.6/src/instance.rs:943-944), and both Clone and Drop do refcount work without requiring a Python<'py> token, so a bare handle in a property map reaches rayon with nothing to stop it. The PhantomData<*mut ()> is what turns graph_properties_copy.cc:35-42’s inverted is_python predicate – which drops the GIL and enables #pragma omp parallel in exactly the object-to-object case – into a compile error.
