Source

fn from_same(s: &Self) -> Self

The diagonal of the lattice: duplicate a value of this same member.

Not Clone. Nine of the fifteen members are Clone and the fifteenth deliberately is not — Py_INCREF needs a Python<'py> token, which is exactly why PyValue has clone_ref and no Clone impl (DESIGN D7, §7). Bounding ConvertFrom’s blanket impl on T: Clone would therefore drop python::object out of the lattice, and convert<python::object, python::object> is value_convert.hh:79, the very first branch the C++ takes.
