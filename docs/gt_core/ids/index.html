§The width decision (DESIGN D5)

graph-tool instantiates adj_list<size_t> and nothing else (src/graph/graph.hh:137), so an adjacency entry costs 16 bytes and a 64-byte cache line holds four. It then stores adjacency positions as pair<uint32_t,uint32_t> (graph_adjacency.hh:620) under that size_t vertex, so the two widths already disagree and nothing asserts it.

Here the width is one crate-wide type alias, not a type parameter. Raw is u32 by default (8 entries per line, 2x graph-tool on the dominant memory stream) and u64 under the wide-index feature. Making it an alias rather than a parameter removes an entire monomorphisation axis from every signature in the port – see the instantiation budget in DESIGN section 10.
