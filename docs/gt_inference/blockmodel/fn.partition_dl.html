The description length of the partition. partition.hh:106.

sizes is _count, one slot per group index (zero for an unoccupied one), and n is _N, the total vertex weight. The group count the prior is written against is _actual_B, the number of occupied groups, which is derived here rather than carried: lgamma(0 + 1) == 0, so the empty slots drop out of the product term on their own and only the lbinom(N - 1, B - 1) term needs the distinction.
