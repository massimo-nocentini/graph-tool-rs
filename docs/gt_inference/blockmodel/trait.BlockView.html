fn move_prob( &self, t: &Transition<'_, Self::D, Self::W>, v: VertexId, c: f64, ) -> f64

The log-probability of the reverse move, synthesised from a recorded transition.

This is get_move_prob (state.hh:1628-1734), the consumer that prices a state which does not yet exist. It takes &self and &Transition – two shared borrows – and therefore coexists with the state-free sparse_ds and precedes the &mut self commit without any interior mutability.
