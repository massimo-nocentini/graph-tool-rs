The same, for kernels that need predecessors.

ALWAYS_DIRECTED is worth declaring only if something can consume it. With a single GraphKernel, no dispatched action can call in_edges at all, because the type parameter is not bounded on Bidirectional and bounding it would break the undirected arms.
