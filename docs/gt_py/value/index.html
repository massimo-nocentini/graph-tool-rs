The shipped value subsets, and the coverage guarantee.

Each invocation of value_subset! is the single source of truth for one dispatch axis: its member list, its accepted-kind array, its narrowing, its kernel trait with the bound the kernel body needs, and its exhaustive match, all from one token list.

The axes mirror graph_properties.hh:78-104 and :166-231. The one deliberate divergence is that long double is not in ScalarV: it has no arithmetic in this port, so the Scalar bound excludes it – which is the mechanism working as intended rather than a gap.
