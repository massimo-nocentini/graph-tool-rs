Trait Allows

pub trait Allows<V: ?Sized>: Mode { }
Expand description

A mode that may be given to V.

This is the bound on ModeOf::Mode, and it is what makes the policy table below unable to be mis-edited: Par permits only a value that can cross a thread, so writing impl ModeOf for PyValue { type Mode = Par; } is error[E0277]: the trait bound PyValue: Sync is not satisfied rather than a silently faster and unsound build. tests/ui/u30_par_mode_for_py_value.rs pins that diagnostic.

The C++ has no analogue because its predicate is a bool computed inside the kernel body (graph_properties_copy.cc:35-42): there is nothing for a compiler to check, and in fact the expression is wrong in both directions.
