Trait ModeOf 

Source 
pub trait ModeOf: PropValue {
    type Mode: Mode + Allows<Self>;
}
Expand description

Which mode a member of the value universe forces.

Note this is not an open policy table: [PropValue] is sealed in gt-core, so the only types that can appear here are the fifteen. A newtype over a raw pyo3::Py<PyAny> cannot be given Mode = Par, because it cannot be a property value at all.

Required Associated Types§

Source

type Mode: Mode + Allows<Self>

The mode this member forces.

Allows<Self> is not decoration: it is the second of DESIGN §7’s three mechanisms, moved from the strategy impls up onto the table itself, so that the table cannot be edited into unsoundness even by someone who never reads the strategy bounds.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
