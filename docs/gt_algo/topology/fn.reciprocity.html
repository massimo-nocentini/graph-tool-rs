Reciprocity: the fraction of edges whose reverse also exists.

E↔ / E, ported from get_reciprocity (topology/graph_reciprocity.cc:29-70) with unit weights and the Python default self_loops=False (topology/__init__.py, edge_reciprocity). The C++ accumulates, per vertex v and per out-neighbour u, Lbd += min(m_uv, m_vu) and L += m_vu (:59-60), so a parallel edge counts towards L with its multiplicity and towards Lbd only as far as the reverse multiplicity supports it. That min is reproduced exactly here: run-lengths in one sorted adjacency row against an equal-range probe in the other, rather than the O(Σ_v d_v²) rescan at :54-58.

Self-loops are excluded from both numerator and denominator (:46-47). A graph with no non-self-loop edge returns f64::NAN, as Lbd / double(L) does at :69.

Bounded on [Bidirectional], so it cannot be asked of an undirected view, where the answer is 1 by construction and the question is a mistake.
