Eigenvector centrality.

Power iteration on the in-adjacency, normalised in L2 each sweep and stopped on the L1 change: graph_eigenvector.hh:56-92. Returns (eigenvalue, sweeps), where the eigenvalue is the last norm computed (:97) and is 0.0 if no sweep ran.

x is the initial iterate as well as the output; slots created by sizing it are seeded with 1/N, reproducing centrality/__init__.py’s vprop.fa = 1. / g.num_vertices().

§Panics

If params.plan does not cover g.vertex_bound(), or if x belongs to another graph.
