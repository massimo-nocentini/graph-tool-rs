1//! Centrality measures.
2//!
3//! Three kernels, ported from `src/graph/centrality/`:
4//!
5//! * [`pagerank`] -- `graph_pagerank.hh:30-100`;
6//! * [`eigenvector`] -- `graph_eigenvector.hh:41-99`;
7//! * [`betweenness`] -- `graph_betweenness.cc:70-94`, which delegates to the
8//!   vendored Brandes in
9//!   `src/boost-workaround/boost/graph/betweenness_centrality.hpp:296-388`.
10//!
11//! ## What this module fixes, and why
12//!
13//! Four defects are corrected here rather than reproduced. Each is a silent
14//! wrong *number*, not a crash, which is why none of them shows up in
15//! graph-tool's own test suite.
16//!
17//! 1. **The odd-iteration writeback is inverted** in both power iterations
18//!    (`graph_pagerank.hh:90-98`, `graph_eigenvector.hh:94-95`). The loop
19//!    maintains the invariant "`rank` names the latest iterate" by swapping
20//!    two property-map *handles* at `:84`; the caller's storage is the one
21//!    `r_temp` names after an odd number of swaps. The fixup then runs
22//!    `put(rank, v, get(r_temp, v))` -- it copies the caller's stale storage
23//!    over the fresh scratch and leaves the caller holding the
24//!    second-to-last iterate. Convergence hides it (the last two iterates
25//!    differ by less than `epsilon` in L1 by construction) but truncation by
26//!    `max_iter` does not. Here the two buffers are ordinary `&mut [f64]`
27//!    bindings and the final copy, when parity calls for one, goes *into*
28//!    the caller's map.
29//! 2. **Division by a zero weighted out-degree.** `graph_pagerank.hh:77`
30//!    computes `rank[s] * weight[e] / deg[s]` for every predecessor `s`
31//!    without checking `deg[s]`. A vertex whose out-edges all carry weight
32//!    zero is pushed onto `sinks` at `:50` -- so its mass is *already*
33//!    redistributed through `p_sink` -- and is nevertheless divided by at
34//!    `:77`, producing `inf` or `NaN` that poisons the whole vector. Here a
35//!    zero weighted out-degree contributes nothing, which is the only
36//!    reading consistent with `:49-50`. With a unity weight map the test is
37//!    unobservable (`deg[s] == 0` implies `s` has no out-edges, so `s` is
38//!    never a predecessor) and const-folds away.
39//! 3. **Division by a zero norm.** `graph_eigenvector.hh:83` divides by
40//!    `sqrt(norm)` unconditionally, so a graph with no edges -- or one whose
41//!    iterate has collapsed to zero -- returns a vector of `NaN`. Here a
42//!    zero norm leaves the iterate alone.
43//! 4. **The Brandes distance map is never reset between sources**
44//!    (`betweenness_centrality.hpp:341-349`: `vincoming`, `vpath_count` and
45//!    `vdependency` are cleared per source, `vdistance` is not, and the BFS
46//!    visitor at `:183-191` only ever *writes* `distance[w]` for a tree
47//!    edge, never for the root). The root keeps whatever distance the
48//!    previous source's BFS left there, so `non_tree_edge` (`:199-209`) can
49//!    match `distance[s] == distance[v] + 1` on an edge pointing back at the
50//!    source, push it into `incoming[s]`, and corrupt both `path_count[s]`
51//!    and the dependency accumulation. Here every BFS sets `dist[s] = 0`.
52//!
53//! ## Determinism
54//!
55//! Every reduction in this module folds in a fixed order, so the result is a
56//! function of the input and the [`Plan`] and of nothing else -- not the
57//! worker count, not the steal order. `p_sink` goes through
58//! [`det_reduce`](gt_core::par::det_reduce) directly; the vertex sweeps use
59//! [`sweep`], which is `det_reduce`'s discipline for the case `det_reduce`
60//! cannot express (its `map` is an `Fn`, so no chunk can hold a `&mut` into
61//! the output). graph-tool reduces `delta`, `norm` and `p_sink` under
62//! `reduction(+:...)` (`graph_pagerank.hh:62, :68`,
63//! `graph_eigenvector.hh:60, :78`) and the betweenness accumulation under
64//! `#pragma omp atomic` (`betweenness_centrality.hpp:275-278`); all four are
65//! reassociated by the schedule, so the low bits move with
66//! `OMP_NUM_THREADS`.

79/// Parameters for a power-iteration centrality.
80#[derive(Clone, Copy, Debug)]
81pub struct PowerIteration {
82    /// Convergence threshold on the L1 change per sweep.
83    pub epsilon: f64,
84    /// Hard cap on sweeps.
85    ///
86    /// `0` means *no* cap, which is what `max_iter > 0 && iter == max_iter`
87    /// (`graph_pagerank.hh:86`) means and what `centrality/__init__.py`
88    /// passes for `max_iter=None`.
89    pub max_iter: usize,
90    /// Partition used for the parallel sweep. Fixed, so the result is
91    /// bit-identical across thread counts.
92    ///
93    /// It partitions the **vertex index space**, not the vertex set:
94    /// `plan.len()` must equal `g.vertex_bound().len()`, which is also the
95    /// length of the property maps involved. For an unfiltered graph the two
96    /// coincide, so `Plan::new(g.num_vertices(), grain)` is what a caller
97    /// writes.
98    pub plan: Plan,
99}

101/// The generator [`det_reduce`] derives per chunk is unused by every
102/// reduction here -- none of them is randomised -- but the signature demands
103/// a root, and a *fixed* root is what keeps the call a pure function of its
104/// arguments.
105const NO_ENTROPY: Seed = Seed([0u8; 32]);
106
107/// How many chunks [`betweenness`] splits its source list into.
108///
109/// Fixed, and deliberately not a function of the pool size: each chunk owns a
110/// full private accumulator pair, so the count sets both the peak memory
111/// (`CHUNKS * (|V| + |E|) * 8` bytes) and the fold order. A thread-derived
112/// count would make the answer move with `RAYON_NUM_THREADS`, which is
113/// exactly what `#pragma omp atomic` at `betweenness_centrality.hpp:277`
114/// does.
115const BETWEENNESS_CHUNKS: usize = 16;

121/// Run `body` over the [`Plan`]'s cover of `out`, in parallel, and fold the
122/// per-chunk `f64` it returns **in chunk order**.
123///
124/// This is [`det_reduce`](gt_core::par::det_reduce) for a sweep that also
125/// *writes*. `det_reduce`'s `map` is an `Fn(Range, &mut ChaCha8Rng) -> T`, so
126/// it can capture only shared state and no chunk can hold a `&mut` into the
127/// output; here the output is cut into the plan's chunks up front with
128/// `split_at_mut`, so each chunk owns its slice and the borrow checker --
129/// not a comment -- is what proves the chunks disjoint.
130///
131/// The fold is a sequential left-to-right `+` over an index-preserving
132/// `collect`, so `sweep` is bit-identical at any worker count, for the same
133/// reason `det_reduce` is.
134///
135/// One `Vec` of `plan.chunks()` slice headers and one of `plan.chunks()`
136/// partials are allocated per call -- per *sweep*, never per vertex.
137///
138/// # Panics
139///
140/// If `plan.len() != out.len()`.
141fn sweep<F>(plan: Plan, out: &mut [f64], body: F) -> f64
142where
143    F: Fn(Range<usize>, &mut [f64]) -> f64 + Sync + Send,
144{
145    assert_eq!(
146        plan.len(),
147        out.len(),
148        "sweep: the plan must cover the output exactly"
149    );
150
151    let mut pieces: Vec<(Range<usize>, &mut [f64])> = Vec::with_capacity(plan.chunks());
152    let mut rest: &mut [f64] = out;
153    for k in 0..plan.chunks() {
154        let r = plan.range(k);
155        let (head, tail) = std::mem::take(&mut rest).split_at_mut(r.len());
156        pieces.push((r, head));
157        rest = tail;
158    }
159    debug_assert!(rest.is_empty(), "Plan::range is not an exact cover");
160
161    let partials: Vec<f64> = pieces
162        .into_par_iter()
163        .map(|(r, piece)| body(r, piece))
164        .collect();
165
166    partials.into_iter().fold(0.0, |a, b| a + b)
167}

169/// Membership in this view's vertex set, indexed by the *unfiltered* vertex
170/// index.
171///
172/// The sweeps walk the index space rather than the vertex set so that a
173/// chunk of the [`Plan`] is a contiguous slice of the property map. A
174/// filtered view's vertex set is not contiguous, so the walk needs an O(1)
175/// membership test and the trait layer offers none; this is it.
176fn active_mask<G: VertexList>(g: G) -> Vec<bool> {
177    let mut mask = vec![false; g.vertex_bound().len()];
178    for v in g.vertices() {
179        mask[v.index()] = true;
180    }
181    mask
182}

184/// The balanced chunk size a [`Plan`] was built with, recovered so that a
185/// second plan over a different length can be cut the same way.
186fn grain_of(plan: Plan) -> usize {
187    plan.len().div_ceil(plan.chunks()).max(1)
188}

190/// Fill the slots a `sized_for` call has just created, leaving any the caller
191/// already owned untouched.
192///
193/// `centrality/__init__.py` seeds a fresh map with `pers` (pagerank) or
194/// `1/N` (eigenvector) before calling the kernel, and the kernel itself
195/// treats whatever it is handed as the initial iterate. Both halves are
196/// preserved: a map that arrives already sized is a warm start, a map that
197/// arrives empty gets the Python front-end's default.
198fn seed_new_slots<P>(data: &mut [f64], had: usize, init: &P)
199where
200    P: ReadProp<VertexTag, Value = f64>,
201{
202    for (i, slot) in data.iter_mut().enumerate().skip(had) {
203        *slot = init.get(VertexId::from_index(i));
204    }
205}

211/// PageRank.
212///
213/// The damping sum is folded through [`gt_core::par::det_reduce`], so the
214/// value does not depend on the thread count. graph-tool's equivalent reduces
215/// under `#pragma omp critical` and therefore does.
216///
217/// The personalisation vector is uniform (`1/N`), which is the default
218/// `pagerank` binds when the caller passes none
219/// (`graph_pagerank.cc:43-44`). For a non-uniform one, call
220/// [`pagerank_with`].
221///
222/// `rank` is the initial iterate as well as the output. Slots that
223/// [`DenseProp::sized_for`](gt_core::prop::DenseProp::sized_for) has to
224/// create are seeded with the personalisation value, so a freshly
225/// constructed map reproduces `centrality/__init__.py`'s
226/// `prop.fa = 1. / g.num_vertices()`.
227///
228/// Returns the number of sweeps performed.
229///
230/// # Panics
231///
232/// If `params.plan` does not cover `g.vertex_bound()`, or if `rank` belongs
233/// to another graph.
234pub fn pagerank<G, W>(
235    g: G,
236    weight: &W,
237    damping: f64,
238    params: PowerIteration,
239    rank: &mut DenseProp<f64, VertexTag>,
240) -> usize
241where
242    G: Bidirectional + VertexList + Sync,
243    W: ReadProp<EdgeTag, Value = f64> + Sync,
244{
245    let n = g.num_vertices();
246    let uniform = if n == 0 { 0.0 } else { 1.0 / n as f64 };
247    pagerank_with(g, weight, &Constant::new(uniform), damping, params, rank)
248}

250/// PageRank with a personalisation vector.
251///
252/// `pers` is `PerMap` of `graph_pagerank.hh:34`. It is *not* normalised here,
253/// exactly as the C++ does not normalise it: the docstring's worked example
254/// feeds it a vector summing to far more than one.
255///
256/// Returns the number of sweeps performed.
257///
258/// # Panics
259///
260/// As [`pagerank`].
261pub fn pagerank_with<G, W, P>(
262    g: G,
263    weight: &W,
264    pers: &P,
265    damping: f64,
266    params: PowerIteration,
267    rank: &mut DenseProp<f64, VertexTag>,
268) -> usize
269where
270    G: Bidirectional + VertexList + Sync,
271    W: ReadProp<EdgeTag, Value = f64> + Sync,
272    P: ReadProp<VertexTag, Value = f64> + Sync,
273{
274    let bound = g.vertex_bound();
275    let len = bound.len();
276    let active = active_mask(g);
277
278    // `init degs` -- `graph_pagerank.hh:44-51`. `out_degree(v, g, weight)` is
279    // `graph_selectors.hh:188-197`, a plain sum over the out-edges, with the
280    // unity specialisation at `:181-186` that this const branch reproduces.
281    let mut deg = vec![0.0f64; len];
282    let mut sinks: Vec<VertexId> = Vec::new();
283    for v in g.vertices() {
284        let k = if W::IS_UNITY {
285            g.out_degree(v) as f64
286        } else {
287            let mut acc = 0.0;
288            for inc in g.out_edges(v) {
289                acc += weight.get(inc.edge);
290            }
291            acc
292        };
293        deg[v.index()] = k;
294        if k == 0.0 {
295            sinks.push(v);
296        }
297    }
298
299    let had = rank.len();
300    let mut view = rank
301        .sized_for(bound)
302        .expect("pagerank: rank map does not belong to this graph");
303    seed_new_slots(view.as_mut_slice(), had, pers);
304
305    let mut scratch = vec![0.0f64; len];
306    let mut cur: &mut [f64] = view.as_mut_slice();
307    let mut next: &mut [f64] = &mut scratch;
308
309    // A second plan for the sink list, cut with the caller's grain so that it
310    // too is a function of `params` alone.
311    let sink_plan = Plan::new(sinks.len(), grain_of(params.plan));
312
313    let d = damping;
314    let mut delta = params.epsilon + 1.0;
315    let mut iter = 0usize;
316    let gr = &g;
317
318    while delta >= params.epsilon {
319        let prev: &[f64] = cur;
320        let sinks_ref = &sinks;
321
322        // `graph_pagerank.hh:60-65`.
323        let p_sink = det_reduce(
324            sink_plan,
325            NO_ENTROPY,
326            |r, _rng| {
327                let mut acc = 0.0;
328                for s in &sinks_ref[r] {
329                    acc += prev[s.index()];
330                }
331                acc
332            },
333            0.0,
334            |a, b| a + b,
335        );
336
337        // `graph_pagerank.hh:67-83`.
338        let active_ref = &active;
339        let deg_ref = &deg;
340        delta = sweep(params.plan, next, |range, out| {
341            let base = range.start;
342            let mut local = 0.0f64;
343            for (offset, slot) in out.iter_mut().enumerate() {
344                let i = base + offset;
345                if !active_ref[i] {
346                    // Not a vertex of this view: carry it through unchanged
347                    // rather than letting the buffer swap alternate two
348                    // meanings in a slot nothing reads.
349                    *slot = prev[i];
350                    continue;
351                }
352                let v = VertexId::from_index(i);
353                let pv = pers.get(v);
354                let mut r = p_sink * pv;
355                for inc in gr.in_edges(v) {
356                    let s = inc.other.index();
357                    let ds = deg_ref[s];
358                    // Defect 2: a zero weighted out-degree is a sink, and a
359                    // sink's mass is already in `p_sink`.
360                    if ds != 0.0 {
361                        r += (prev[s] * weight.get(inc.edge)) / ds;
362                    }
363                }
364                let nv = (1.0 - d) * pv + d * r;
365                local += (nv - prev[i]).abs();
366                *slot = nv;
367            }
368            local
369        });
370
371        std::mem::swap(&mut cur, &mut next);
372        iter += 1;
373        if params.max_iter > 0 && iter == params.max_iter {
374            break;
375        }
376    }
377
378    // Defect 1, the right way round: after an odd number of swaps the latest
379    // iterate is in the scratch buffer and `next` is the caller's map.
380    if iter % 2 == 1 {
381        next.copy_from_slice(cur);
382    }
383    iter
384}

390/// Eigenvector centrality.
391///
392/// Power iteration on the *in*-adjacency, normalised in L2 each sweep and
393/// stopped on the L1 change: `graph_eigenvector.hh:56-92`. Returns
394/// `(eigenvalue, sweeps)`, where the eigenvalue is the last norm computed
395/// (`:97`) and is `0.0` if no sweep ran.
396///
397/// `x` is the initial iterate as well as the output; slots created by
398/// sizing it are seeded with `1/N`, reproducing
399/// `centrality/__init__.py`'s `vprop.fa = 1. / g.num_vertices()`.
400///
401/// # Panics
402///
403/// If `params.plan` does not cover `g.vertex_bound()`, or if `x` belongs to
404/// another graph.
405pub fn eigenvector<G, W>(
406    g: G,
407    weight: &W,
408    params: PowerIteration,
409    x: &mut DenseProp<f64, VertexTag>,
410) -> (f64, usize)
411where
412    G: Bidirectional + VertexList + Sync,
413    W: ReadProp<EdgeTag, Value = f64> + Sync,
414{
415    let bound = g.vertex_bound();
416    let len = bound.len();
417    let active = active_mask(g);
418    let n = g.num_vertices();
419    let uniform = if n == 0 { 0.0 } else { 1.0 / n as f64 };
420
421    let had = x.len();
422    let mut view = x
423        .sized_for(bound)
424        .expect("eigenvector: centrality map does not belong to this graph");
425    seed_new_slots(
426        view.as_mut_slice(),
427        had,
428        &Constant::<f64, VertexTag>::new(uniform),
429    );
430
431    let mut scratch = vec![0.0f64; len];
432    let mut cur: &mut [f64] = view.as_mut_slice();
433    let mut next: &mut [f64] = &mut scratch;
434
435    let mut norm = 0.0f64;
436    let mut delta = params.epsilon + 1.0;
437    let mut iter = 0usize;
438    let gr = &g;
439    let active_ref = &active;
440
441    while delta >= params.epsilon {
442        let prev: &[f64] = cur;
443
444        // `graph_eigenvector.hh:58-72`: build `c_temp` and accumulate the
445        // squared norm in the same pass.
446        let sq = sweep(params.plan, next, |range, out| {
447            let base = range.start;
448            let mut acc = 0.0f64;
449            for (offset, slot) in out.iter_mut().enumerate() {
450                let i = base + offset;
451                if !active_ref[i] {
452                    *slot = prev[i];
453                    continue;
454                }
455                let v = VertexId::from_index(i);
456                let mut s = 0.0f64;
457                for inc in gr.in_edges(v) {
458                    s += weight.get(inc.edge) * prev[inc.other.index()];
459                }
460                *slot = s;
461                // `power(c_temp[v], 2)` -- `__gnu_cxx::power` is `x * x`.
462                acc += s * s;
463            }
464            acc
465        });
466
467        norm = sq.sqrt();
468
469        // `graph_eigenvector.hh:76-85`. Defect 3: `norm == 0` means the
470        // iterate is identically zero, and `0 / 0` is not its normalisation.
471        let scale = if norm == 0.0 { 1.0 } else { norm };
472        delta = sweep(params.plan, next, |range, out| {
473            let base = range.start;
474            let mut acc = 0.0f64;
475            for (offset, slot) in out.iter_mut().enumerate() {
476                let i = base + offset;
477                if !active_ref[i] {
478                    continue;
479                }
480                *slot /= scale;
481                acc += (*slot - prev[i]).abs();
482            }
483            acc
484        });
485
486        std::mem::swap(&mut cur, &mut next);
487        iter += 1;
488        if params.max_iter > 0 && iter == params.max_iter {
489            break;
490        }
491    }
492
493    if iter % 2 == 1 {
494        next.copy_from_slice(cur);
495    }
496    (norm, iter)
497}

503/// Per-chunk scratch for [`betweenness`].
504///
505/// Allocated once per chunk and reused across that chunk's sources, which is
506/// what `firstprivate(vincoming, vdistance, vdependency, vpath_count)`
507/// (`betweenness_centrality.hpp:331-333`) buys in the C++: after the first
508/// source no `Vec` in here grows again.
509struct Brandes {
510    /// BFS distance, `-1` standing in for boost's `white` colour.
511    dist: Vec<i64>,
512    /// `sigma`: number of shortest paths from the source.
513    sigma: Vec<f64>,
514    /// `delta`: dependency accumulator.
515    dep: Vec<f64>,
516    /// Shortest-path DAG predecessors, as `(predecessor, edge)`.
517    incoming: Vec<Vec<(VertexId, EdgeId)>>,
518    /// Vertices in BFS *dequeue* order; boost pushes these on a stack
519    /// (`:173-176`) and pops it, so the accumulation walks this in reverse.
520    order: Vec<VertexId>,
521    /// The BFS frontier.
522    queue: VecDeque<VertexId>,
523    /// Vertex-betweenness partial for this chunk.
524    vb: Vec<f64>,
525    /// Edge-betweenness partial for this chunk.
526    eb: Vec<f64>,
527}
528
529impl Brandes {
530    fn new(vlen: usize, elen: usize) -> Self {
531        Brandes {
532            dist: vec![-1; vlen],
533            sigma: vec![0.0; vlen],
534            dep: vec![0.0; vlen],
535            incoming: vec![Vec::new(); vlen],
536            order: Vec::new(),
537            queue: VecDeque::new(),
538            vb: vec![0.0; vlen],
539            eb: vec![0.0; elen],
540        }
541    }
542
543    /// One source: BFS, then the reverse-order dependency accumulation.
544    fn run<G>(&mut self, g: G, verts: &[VertexId], s: VertexId)
545    where
546        G: GraphRef,
547    {
548        // `betweenness_centrality.hpp:343-348`, plus the `dist` reset the C++
549        // omits (defect 4).
550        for v in verts {
551            let i = v.index();
552            self.incoming[i].clear();
553            self.sigma[i] = 0.0;
554            self.dep[i] = 0.0;
555            self.dist[i] = -1;
556        }
557        self.order.clear();
558        self.queue.clear();
559
560        let si = s.index();
561        self.sigma[si] = 1.0;
562        self.dist[si] = 0;
563        self.queue.push_back(s);
564
565        while let Some(u) = self.queue.pop_front() {
566            // boost calls `examine_vertex` on *dequeue*
567            // (`breadth_first_search.hpp`), so this is the order the stack
568            // at `:173-176` receives.
569            self.order.push(u);
570            let ui = u.index();
571            let du = self.dist[ui];
572            let su = self.sigma[ui];
573            for inc in g.out_edges(u) {
574                let w = inc.other;
575                if w == u {
576                    // `if (v == w) return;` -- `:203-204`. A self-loop can
577                    // never shorten a path and must never enter `incoming`.
578                    continue;
579                }
580                let wi = w.index();
581                if self.dist[wi] < 0 {
582                    // `tree_edge`, `:183-191`.
583                    self.dist[wi] = du + 1;
584                    self.sigma[wi] = su;
585                    self.incoming[wi].push((u, inc.edge));
586                    self.queue.push_back(w);
587                } else if self.dist[wi] == du + 1 {
588                    // `non_tree_edge`, `:199-209`. Parallel edges are
589                    // distinct shortest paths, and each is pushed.
590                    self.sigma[wi] += su;
591                    self.incoming[wi].push((u, inc.edge));
592                }
593            }
594        }
595
596        // `betweenness_centrality.hpp:357-377`.
597        for idx in (0..self.order.len()).rev() {
598            let u = self.order[idx];
599            let ui = u.index();
600            let su = self.sigma[ui];
601            for &(v, e) in &self.incoming[ui] {
602                let vi = v.index();
603                let factor = (self.sigma[vi] / su) * (1.0 + self.dep[ui]);
604                self.dep[vi] += factor;
605                self.eb[e.index()] += factor;
606            }
607            if u != s {
608                self.vb[ui] += self.dep[ui];
609            }
610        }
611    }
612}

614/// Betweenness centrality (Brandes).
615///
616/// Unweighted, with **every** vertex of the view as a pivot -- the
617/// `pivots = list(g.vertices())` default of
618/// `graph_tool.centrality.betweenness`. Both maps are zeroed first
619/// (`init_centrality_map`, `betweenness_centrality.hpp:311-312`) and the
620/// result is *unnormalised*: graph-tool's `norm=True` is a separate pass
621/// (`normalize_betweenness`, `graph_betweenness.cc:31-68`).
622///
623/// On an undirected view every pair is counted from both endpoints, so both
624/// maps are halved at the end, exactly as
625/// `divide_centrality_by_two` (`:384-387`) does.
626///
627/// # Panics
628///
629/// If either map belongs to another graph.
630pub fn betweenness<G>(
631    g: G,
632    vertex_bc: &mut DenseProp<f64, VertexTag>,
633    edge_bc: &mut DenseProp<f64, EdgeTag>,
634) where
635    G: GraphRef + VertexList + Sync,
636{
637    let vbound = g.vertex_bound();
638    let ebound = g.edge_bound();
639    let vlen = vbound.len();
640    let elen = ebound.len();
641
642    let verts: Vec<VertexId> = g.vertices().collect();
643
644    // `betweenness_centrality.hpp:311-312`.
645    let mut vview = vertex_bc
646        .sized_for(vbound)
647        .expect("betweenness: vertex map does not belong to this graph");
648    vview.as_mut_slice().fill(0.0);
649    let mut eview = edge_bc
650        .sized_for(ebound)
651        .expect("betweenness: edge map does not belong to this graph");
652    eview.as_mut_slice().fill(0.0);
653
654    let plan = Plan::new(verts.len(), verts.len().div_ceil(BETWEENNESS_CHUNKS).max(1));
655    let gr = &g;
656    let verts_ref = &verts;
657
658    let partials: Vec<(Vec<f64>, Vec<f64>)> = (0..plan.chunks())
659        .into_par_iter()
660        .map(|k| {
661            let mut scratch = Brandes::new(vlen, elen);
662            for &s in &verts_ref[plan.range(k)] {
663                scratch.run(*gr, verts_ref, s);
664            }
665            (scratch.vb, scratch.eb)
666        })
667        .collect();
668
669    // Sequential, chunk order: the association is the plan's, not the pool's.
670    let vout = vview.as_mut_slice();
671    let eout = eview.as_mut_slice();
672    for (pv, pe) in &partials {
673        for (a, b) in vout.iter_mut().zip(pv) {
674            *a += *b;
675        }
676        for (a, b) in eout.iter_mut().zip(pe) {
677            *a += *b;
678        }
679    }
680
681    if !<G::Dir as Dir>::DIRECTED {
682        for a in vout.iter_mut() {
683            *a /= 2.0;
684        }
685        for a in eout.iter_mut() {
686            *a /= 2.0;
687        }
688    }
689}
