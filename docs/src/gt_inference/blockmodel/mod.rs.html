10// `audit_absolute` is the O(E + B^2) from-scratch recompute behind the
11// `audit-full` feature (Cargo.toml: the replacement for graph-tool's
12// `__test__ = True`). U26 declared it `pub` but it was unreachable from
13// outside the crate, so its own acceptance sweep had to live in a private
14// `mod sweep` inside audit.rs. Exported here under the same feature gate that
15// guards the cost, so the drift check can be driven from an integration test
16// or a bench.

19pub use cache::Cache;
20// `entropy` is a private module, so anything it declares `pub` is still
21// unreachable from outside the crate unless it is named here. Three items were
22// missing and are now listed:
23//
24// * `edges_dl` (`entropy.hh:293-298`), a description-length term of the same
25//   functional as its sibling `partition_dl`, which *was* listed;
26// * `sparse_ds` and `dense_ds` (`state.hh:1224-1255` / `:1138-1220`), the two
27//   pricing entry points. Both are `pub`, both take only public types
28//   (`delta::Delta`, `EntropyParams`, `Cache`, and for `dense_ds` a
29//   `state::BlockView`), and without this line no integration test and no
30//   bench outside `gt-inference` can name either one.
31pub use entropy::{
32    EntropyParams, dense_ds, edges_dl, eterm, eterm_dense, partition_dl, sparse_ds, vterm,
33};
34// `ScanDir` is a bound on `record`/`scan`, so it has to be nameable outside
35// the crate: without it a caller can only write *monomorphic* wrappers
36// (`record::<_, Directed, _>`), never one generic over directedness, because
37// the `S::D: ScanDir<G>` obligation cannot be written down. Calling
38// `record`/`scan` at a concrete directedness never needs to name it.
39pub use record::{ScanDir, propagate, record, scan};
40// `state` is private too. Alongside the three traits and `GroupLocks`, the
41// concrete implementation U24 landed has to be nameable from outside the
42// crate or it is dead on arrival: `Aggregates` is the storage the pricing and
43// commit paths both address, `BlockState` is the only type in the workspace
44// that implements all three traits, `RowImage` is what `Aggregates::image`
45// returns, and `StampMismatch` is the error half of `BlockState`'s inherent
46// `try_commit` / `try_commit_shared` -- which exist precisely because
47// `BlockCommit::commit` returns `Receipt` by value and can refuse only by
48// panicking.
49pub use state::{
50    Aggregates, BlockCommit, BlockCommitShared, BlockState, BlockView, GroupLocks, RowImage,
51    StampMismatch,
52};
