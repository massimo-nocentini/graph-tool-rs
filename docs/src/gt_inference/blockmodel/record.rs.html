1//! Recording a transition, and projecting it up a hierarchy.
2//!
3//! ## The three things this module owes the C++, and the one it refuses it
4//!
5//! `modify_entries_dispatch` (`blockmodel/entries.hh:227-320`) is thirty lines
6//! of template with four independent axes -- `single`, directedness, `r`
7//! present, `nr` present -- and every one of them is resolved at
8//! monomorphisation here exactly as it is there: `SINGLE` is a const generic,
9//! `D::DIRECTED` is an associated const, and the two endpoint tests are
10//! `Option::is_some` on a four-byte niche.
11//!
12//! Three details the port must not lose, and does not:
13//!
14//! * the undirected self-loop is **traversed twice** -- `out_edges_range` on
15//!   an undirected view walks the whole adjacency block, out-half and in-half
16//!   (`graph_adaptor.hh:199-207`, `graph_adjacency.hh:1102-1108`) -- so its
17//!   weight is accumulated and halved (`entries.hh:274-290`);
18//! * a pair containing *both* endpoints belongs to `r`'s half-fields, because
19//!   `get_field` (`:108-119`) tests `r` first. Routing it anywhere else keys
20//!   one pair under two cells, and the `else` arms at `:258-261`/`:311-314`
21//!   are that routing;
22//! * `auto s = b[u]` (`:250`, `:304`) is read unchecked although
23//!   `state.hh:126-131` deliberately sets `_b[v]` to the null group for
24//!   zero-weight vertices. Here that value is an `Option<Group>` and a `None`
25//!   is **reported**, never skipped: skipping produces a delta quietly short
26//!   by one edge's weight, which is strictly worse than the C++'s
27//!   out-of-range index because nothing downstream can detect it. See
28//!   [`no_group`].
29//!
30//! The one it refuses is the `single` self-loop correction. `entries.hh:283`
31//! guards the `nr` half of the halving with `if constexpr (!single)` while the
32//! `r` half runs unguarded, so a `single` (`r == nr`) move over an undirected
33//! self-loop records `+w` on the pair `(r, r)` for a transition that changes
34//! nothing. It is latent in graph-tool -- `move_vertex` returns at
35//! `state.hh:280` when `r == nr` and `virtual_move_groups` at `:1341`, so the
36//! entries are computed and thrown away -- but it is still a wrong delta, and
37//! [`scan`] drops the guard. With `SINGLE` the two halves then land on the
38//! same cell (`nr`'s half-fields *are* `r`'s, `:231`) and cancel, which is the
39//! correct answer.
40

53/// A vertex the recorder needs a group for has none.
54///
55/// `#[cold]` and out of line: this is the `auto s = b[u]` of `entries.hh:250`
56/// and `:304`, where the C++ indexes `_mrs`/`_emat` with
57/// `numeric_limits<int64_t>::max()` and reads whatever is there. A skip would
58/// be quieter and worse -- the recorded delta would be short by this edge's
59/// weight and every consumer would price, apply and audit it without noticing
60/// -- so the only two honest answers are a wrong index and a stopped process.
61#[cold]
62#[inline(never)]
63fn no_group(u: VertexId, map: &'static str) -> ! {
64    panic!(
65        "vertex {} has no group under `{map}`: a zero-weight vertex \
66         (`state.hh:126-131` sets `_b[v]` to the null group there) is incident \
67         to the vertex being moved, so the recorded delta would be short by \
68         this edge's weight",
69        u.index()
70    )
71}
72
73/// A group the hierarchy projection has no image for.
74///
75/// `propagate_entries` reads `_b[t]` unchecked (`state.hh:1113`). Same
76/// argument as [`no_group`]: an unprojectable group cannot be dropped from the
77/// delta, because the level above would then be short by that pair's weight.
78#[cold]
79#[inline(never)]
80fn no_image(r: Group) -> ! {
81    panic!(
82        "group {r:?} has no image one level up: `propagate_entries` \
83         (`state.hh:1110-1115`) projects every entry endpoint through `_b`, \
84         and dropping one would leave the level above short by that pair's \
85         weight"
86    )
87}

89/// `b[u]`, the group of a neighbour **before** the move.
90#[inline]
91fn group_of<S: BlockView>(st: &S, u: VertexId) -> Group {
92    match st.group_of(u) {
93        Some(g) => g,
94        None => no_group(u, "b"),
95    }
96}
97
98/// `nb[u]`, the group of a neighbour **after** the move.
99#[inline]
100fn new_group<F: Fn(VertexId) -> Option<Group>>(nb: &F, u: VertexId) -> Group {
101    match nb(u) {
102        Some(g) => g,
103        None => no_group(u, "nb"),
104    }
105}

111/// The part of [`scan`] that only exists when the graph is directed.
112///
113/// ## Why this trait exists rather than an `if D::DIRECTED` branch
114///
115/// `entries.hh:292` is `if constexpr (is_directed_v<g_t>)` around a loop over
116/// `in_edges_range(v, g)`, and `:308` names `_r_in_field`. Neither has an
117/// undirected spelling *at all* in this port, and deliberately so:
118///
119/// * [`Bidirectional`] is implemented for no undirected view, because
120///   `in_edges(v, undirected_adaptor)` returns a default-constructed empty
121///   range (`graph_adaptor.hh:219-227`) and a generic algorithm that walked it
122///   would get a wrong answer rather than an error;
123/// * `Field::<Undirected>` has exactly two inhabitants, so `R_IN` is
124///   unnameable there -- which is the whole point of
125///   [`Field`](gt_core::dir::Field) being total.
126///
127/// A plain `if D::DIRECTED { g.in_edges(v) }` therefore does not typecheck for
128/// generic `D`, however dead the branch is. Dispatching on the *directedness
129/// type* does, costs nothing (both methods monomorphise to either the loop or
130/// an empty body), and moves the `G: Bidirectional` requirement to exactly the
131/// impl that needs it: a directed block model can only be scanned through a
132/// view that has in-edges, and an undirected one only through a view whose
133/// `out_edges` is the whole incidence run.
134pub trait ScanDir<G: GraphRef>: Dir + Sized {
135    /// The half-field a pair `(x, r)` -- `r` as the *sink* -- is keyed by.
136    ///
137    /// `get_field_rnr<true, false>` (`entries.hh:90-103`): `_r_in_field` when
138    /// directed, and `_r_out_field` when not, there being no in-half to speak
139    /// of. [`DeltaBuf::touch`] folds the `s == t` case onto the out-half by
140    /// itself, exactly as `:97` does.
141    fn r_sink() -> Field<Self>;
142
143    /// `in_degree(v, g, eweight)` with a unit `eweight`.
144    ///
145    /// Zero when undirected: `in_degree(u, undirected_adaptor)` is literally
146    /// `return 0` (`graph_adaptor.hh:322-330`), which is why
147    /// `state.hh:225-226` guards `_mrm[r] += kin` with `if constexpr
148    /// (is_directed_v<g_t>)`.
149    fn in_degree<W: Weight>(g: G, v: VertexId) -> W;
150
151    /// The in-edge pass of `modify_entries_dispatch` (`entries.hh:292-318`).
152    ///
153    /// A no-op when undirected, where the C++ does not instantiate it either.
154    fn in_pass<const SINGLE: bool, S, F>(
155        st: &S,
156        g: G,
157        v: VertexId,
158        mv: MoveKey,
159        nb: &F,
160        buf: &mut DeltaBuf<Self, S::W>,
161    ) where
162        S: BlockView<D = Self>,
163        F: Fn(VertexId) -> Option<Group>;
164}
165
166impl<G: Bidirectional> ScanDir<G> for Directed {
167    #[inline]
168    fn r_sink() -> Field<Directed> {
169        Field::<Directed>::R_IN
170    }
171
172    #[inline]
173    fn in_degree<W: Weight>(g: G, v: VertexId) -> W {
174        W::from_i64(g.in_degree(v) as i64)
175    }
176
177    fn in_pass<const SINGLE: bool, S, F>(
178        st: &S,
179        g: G,
180        v: VertexId,
181        mv: MoveKey,
182        nb: &F,
183        buf: &mut DeltaBuf<Directed, S::W>,
184    ) where
185        S: BlockView<D = Directed>,
186        F: Fn(VertexId) -> Option<Group>,
187    {
188        let one = S::W::from_i64(1);
189        // `insert_delta_rnr<single, false, true>`: with `single` the `nr`
190        // half-fields *are* `r`'s (`:231` nulls the second endpoint).
191        let nr_in = if SINGLE {
192            Field::<Directed>::R_IN
193        } else {
194            Field::<Directed>::NR_IN
195        };
196        let mut resolve = |a: Group, b: Group| st.resolve(a, b);
197
198        for inc in g.in_edges(v) {
199            let u = inc.other;
200            // `:299-300`. The self-loop was already counted by the out-pass.
201            if u == v {
202                continue;
203            }
204
205            if mv.from.is_some() {
206                // `insert_delta_rnr<true, false, false>(s, r, ew)` (`:306`).
207                buf.touch::<false>(Field::<Directed>::R_IN, group_of(st, u), one, &mut resolve);
208            }
209
210            if let Some(nr) = mv.to {
211                let s = new_group(nb, u);
212                if Some(s) != mv.from {
213                    // `insert_delta_rnr<single, false, true>(s, nr, ew)`
214                    // (`:313`).
215                    buf.touch::<true>(nr_in, s, one, &mut resolve);
216                } else {
217                    // `insert_delta_rnr<true, true, true>(s, nr, ew)` (`:315`)
218                    // with `s == r`: the pair `(r, nr)`, which `get_field`
219                    // routes to `r`'s out-half because it tests `r` first.
220                    buf.touch::<true>(Field::<Directed>::R_OUT, nr, one, &mut resolve);
221                }
222            }
223        }
224    }
225}

258/// Record the transition "move `v` from `mv.from` to `mv.to`".
259///
260/// `st` is borrowed **shared** and does not appear in the return type: the
261/// recording's lifetime is the *workspace's*. That is the whole ownership
262/// inversion, and it is why the caller can subsequently take `&mut st`.
263///
264/// Ports `modify_entries` (`entries.hh:322`) + `get_move_entries`
265/// (`state.hh:1062`). `nb` is the `_vset`-backed ad-hoc property map of
266/// `state.hh:451-459`, here an ordinary closure rather than a
267/// `make_adhoc_prop`.
268///
269/// `slots` is `num_vertices(_bg)`, the block-graph index bound that
270/// `modify_entries` takes as `B` (`entries.hh:228`); `vw` is `_vweight[v]`,
271/// the `n` of `virtual_move_groups` (`state.hh:1331`, `:1394`). Both are
272/// parameters for the same reason: [`BlockView`] exposes the *occupied* group
273/// count and no per-vertex weight, so neither can be recovered from `st`. See
274/// the crate docs' note on `dr`'s sign -- graph-tool passes `-n` and `+n` into
275/// `entries_dS` (`:1349`), while [`MoveHeader::dr`] is the weight *leaving*
276/// `r` and is therefore positive.
277///
278/// Only level 0 is recorded. `get_move_entries`' `visit_coupled_if`
279/// (`state.hh:1068-1075`) is [`propagate`], which the caller runs once per
280/// level because the projection `_b` differs per level and is not reachable
281/// from a single `st`.
282///
283/// # Panics
284///
285/// If a neighbour of `v` has no group. See this module's `no_group`.
286#[allow(clippy::too_many_arguments)]
287pub fn record<'w, S, G, F>(
288    st: &S,
289    g: G,
290    v: VertexId,
291    mv: MoveKey,
292    nb: &F,
293    slots: usize,
294    vw: S::W,
295    ws: &'w mut Workspace<S::D, S::W>,
296) -> Recording<'w, S::D, S::W>
297where
298    S: BlockView,
299    S::D: ScanDir<G>,
300    G: GraphRef,
301    F: Fn(VertexId) -> Option<Group>,
302{
303    // `_degs[v] = {kin, kout}` (`state.hh:220-222`) with a unit `_eweight`:
304    // this recorder carries no edge-weight map, so an edge's weight is one and
305    // multiplicity is parallel edges. `out_degree` on an undirected view is
306    // `degree` on the underlying graph (`graph_adaptor.hh:315-319`), i.e. a
307    // self-loop counts twice -- which is what `_mrp[r] += kout` (`:224`)
308    // expects.
309    let hdr = MoveHeader {
310        r: mv.from,
311        nr: mv.to,
312        r_img: st.end_image(mv.from),
313        nr_img: st.end_image(mv.to),
314        dkin: <S::D as ScanDir<G>>::in_degree(g, v),
315        dkout: S::W::from_i64(g.out_degree(v) as i64),
316        dr: vw,
317        dnr: vw,
318    };
319    let stamp = st.stamp();
320    let mut rec = Recording::new(&mut ws.stack, hdr, stamp);
321
322    // `modify_entries` (`entries.hh:322-331`): the dispatch *is* the
323    // comparison, and `single` is the only thing it decides.
324    if mv.from == mv.to {
325        scan::<true, S, G, F, S::D>(st, g, v, mv, nb, slots, rec.level_mut(0));
326    } else {
327        scan::<false, S, G, F, S::D>(st, g, v, mv, nb, slots, rec.level_mut(0));
328    }
329    rec
330}

336/// The single-pass recorder. `modify_entries_dispatch<single>`
337/// (`entries.hh:227-320`).
338///
339/// `SINGLE` is a const generic exactly as C++'s `single` is a template
340/// parameter, and it selects the half-field at every touch site, so the
341/// monomorphised body has the same shape. `D::DIRECTED` gates the in-edge pass
342/// with no runtime branch.
343///
344/// Two details the C++ encodes and a port must not lose: the undirected
345/// self-loop weight is accumulated and **halved** (`:276-292`, with
346/// `assert(self_weight % 2 == 0)`), and `auto s = b[u]` (`:250`, `:304`) is
347/// unchecked although `state.hh:126-128` sets `_b[v]` to the null group for
348/// zero-weight vertices. Here that is an `Option<Group>`; a `None` neighbour
349/// must be `debug_assert`ed or reported, never silently skipped, because a
350/// skip produces a delta quietly short by one edge's weight.
351///
352/// `slots` is `B`, the block-graph index bound `set_move` grows the field
353/// table to (`entries.hh:63-64`). Calling this is what *begins* the buffer;
354/// anything it held is cleared first, in O(#entries).
355///
356/// # Panics
357///
358/// If a neighbour of `v` has no group (this module's `no_group`), or if a
359/// group index is at or beyond `slots`.
360pub fn scan<const SINGLE: bool, S, G, F, D: ScanDir<G>>(
361    st: &S,
362    g: G,
363    v: VertexId,
364    mv: MoveKey,
365    nb: &F,
366    slots: usize,
367    buf: &mut DeltaBuf<D, S::W>,
368) where
369    S: BlockView<D = D>,
370    G: GraphRef,
371    F: Fn(VertexId) -> Option<Group>,
372{
373    debug_assert_eq!(
374        SINGLE,
375        mv.from == mv.to,
376        "`modify_entries` (entries.hh:324) dispatches `single` on exactly \
377         `r == nr`"
378    );
379
380    // `set_move(r, single ? null_group : nr, B)` (`:231`). `mv` keeps both
381    // endpoints -- the C++'s local `nr` stays non-null under `single` and is
382    // still tested at `:255` -- while the *buffer's* key folds `nr` onto `r`.
383    buf.begin(
384        MoveKey {
385            from: mv.from,
386            to: if SINGLE { None } else { mv.to },
387        },
388        slots,
389    );
390
391    let one = S::W::from_i64(1);
392    // `insert_delta_rnr<single, true, _>`: the `nr` out-half, which is `r`'s
393    // when `single`.
394    let nr_out = if SINGLE {
395        Field::<D>::R_OUT
396    } else {
397        Field::<D>::NR_OUT
398    };
399    let r_sink = <D as ScanDir<G>>::r_sink();
400    let mut resolve = |a: Group, b: Group| st.resolve(a, b);
401
402    // Undirected only: how many times a self-loop was *traversed*. With a unit
403    // edge weight this is `self_weight` (`:239`) exactly, and counting rather
404    // than summing is what lets the halving at `:277` be an integer division
405    // by two on a count -- [`Weight`] has no `Div`, and `to_f64`-and-back
406    // would be lossy for the very type (`f64`) it would be introduced for.
407    let mut self_traversals = 0usize;
408
409    for inc in g.out_edges(v) {
410        let u = inc.other;
411
412        if mv.from.is_some() {
413            // `insert_delta_rnr<true, true, false>(r, s, ew)` (`:252`).
414            // `b[u]` is read only where the C++ *uses* it: with `r` null the
415            // value at `:250` is dead, and a dead read must not panic.
416            buf.touch::<false>(Field::<D>::R_OUT, group_of(st, u), one, &mut resolve);
417        }
418
419        if let Some(nr) = mv.to {
420            // `:257-259`: `v` itself is already in `nr`, whatever `nb` says.
421            let s = if u == v { nr } else { new_group(nb, u) };
422            if Some(s) != mv.from {
423                // `insert_delta_rnr<single, true, true>(nr, s, ew)` (`:262`).
424                buf.touch::<true>(nr_out, s, one, &mut resolve);
425            } else {
426                // `insert_delta_rnr<true, false, true>(nr, s, ew)` (`:264`)
427                // with `s == r`: the pair `(nr, r)`, keyed by `r`'s sink half
428                // because `get_field` tests `r` first.
429                buf.touch::<true>(r_sink, nr, one, &mut resolve);
430            }
431        }
432
433        if !D::DIRECTED && u == v {
434            // `:269-272`.
435            self_traversals += 1;
436        }
437    }
438
439    <D as ScanDir<G>>::in_pass::<SINGLE, S, F>(st, g, v, mv, nb, buf);
440
441    if !D::DIRECTED && self_traversals != 0 {
442        // `assert(int64_t(self_weight) % 2 == 0)` (`:279`): an undirected view
443        // yields a self-loop from both halves of the adjacency block, so the
444        // traversal count is even by construction.
445        debug_assert_eq!(
446            self_traversals % 2,
447            0,
448            "an undirected self-loop is traversed twice (entries.hh:279)"
449        );
450        let half = S::W::from_i64((self_traversals / 2) as i64);
451        if let Some(r) = mv.from {
452            // `insert_delta_rnr<true, true, true>(r, r, self_weight)` (`:282`).
453            buf.touch::<true>(Field::<D>::R_OUT, r, half, &mut resolve);
454        }
455        if let Some(nr) = mv.to {
456            // `insert_delta_rnr<single, true, false>(nr, nr, self_weight)`
457            // (`:288`), **without** the `if constexpr (!single)` of `:283`.
458            // See this module's header: with `single` the guard leaves `+w` on
459            // `(r, r)` for a transition that changes nothing, and dropping it
460            // makes the two halves cancel on the one cell they share.
461            buf.touch::<false>(nr_out, nr, half, &mut resolve);
462        }
463    }
464}

467// propagate
468// ---------------------------------------------------------------------------

470/// Project level `l`'s entries onto level `l + 1`.
471///
472/// Ports `propagate_entries` (`state.hh:1099-1117`). Streams straight from the
473/// below-level entries into the above-level buffer: materialising an
474/// intermediate vector is not required by the borrow checker
475/// ([`DeltaStack::below_above`](crate::delta::DeltaStack::below_above) already
476/// proves the disjointness) and `entries_op` allocates nothing.
477///
478/// `b_of` is level `l + 1`'s `_b`, indexed by a level-`l` group -- the block
479/// graph's vertices *are* the level below's groups. `slots` is that level's
480/// `num_vertices(_bg)` (`:1107`).
481///
482/// The above-level key is `{_b[r], _b[nr]}` (`:1103-1106`), with one
483/// normalisation the C++ does not perform: two groups that share a parent
484/// project to one, and a [`MoveKey`] whose endpoints are equal and present is
485/// not a value [`DeltaBuf`] expects. Collapsing it to a single endpoint is
486/// what `set_move(r, single ? null : nr, ..)` does one level down and selects
487/// the identical cells -- `get_field` tests `_rnr.first` first, so `nr`'s
488/// half-fields are unreachable either way.
489///
490/// Allocates nothing once the buffers are warm: `begin` drains into the
491/// existing field table and the entry vector is reused.
492///
493/// # Panics
494///
495/// If `b_of` has no image for an entry endpoint (this module's `no_image`),
496/// or if `l + 1 >= rec.n_levels()`.
497pub fn propagate<W: Weight, D: Dir, P>(
498    rec: &mut Recording<'_, D, W>,
499    l: usize,
500    b_of: &P,
501    slots: usize,
502    resolve: &mut impl crate::delta::Resolve<W>,
503) -> Result<(), OutOfPlane>
504where
505    P: Fn(Group) -> Option<Group>,
506{
507    let (below, above) = rec.below_above(l);
508
509    // `group_t r = (u != _null_group) ? _b[u] : _null_group` (`:1103-1105`):
510    // an absent endpoint stays absent, and an unplaced group is null too --
511    // the C++ reaches the same value by reading `_b[u]` unchecked.
512    let mv = below.move_key();
513    let from = mv.from.and_then(b_of);
514    let to = mv.to.and_then(b_of);
515    let to = if to == from { None } else { to };
516    above.begin(MoveKey { from, to }, slots);
517
518    for e in below.entries() {
519        // `if (delta == 0) return;` (`:1114`). A zero entry projects to a zero
520        // entry; creating it would only cost the above level a cell.
521        if e.delta == W::ZERO {
522            continue;
523        }
524        let r = match b_of(e.r) {
525            Some(g) => g,
526            None => no_image(e.r),
527        };
528        let s = match b_of(e.s) {
529            Some(g) => g,
530            None => no_image(e.s),
531        };
532        // `insert_delta<true>(_b[t], _b[w], delta)` (`:1115-1116`), made
533        // total: the C++ falls through `get_field` to the shared `_dummy`
534        // cell here, where two out-of-plane pairs accumulate into one entry.
